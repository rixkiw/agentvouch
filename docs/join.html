Vouch for AgentVouch

3 minutes · gas only · no fees, no approvals, no funds move

Give one agent your word. That's the whole ask.

AgentVouch is a public trust graph for Agent IDs. A vouch is one short on-chain statement: “this agent is worth dealing with”. Only Agent ID holders can write one, and only Agent ID holders can receive one — that's what makes the reputation un-buyable. Your vouch is revocable any time and costs nothing but BNB gas.

What you need

✅ A Binance Agent ID (name.ai) — claim free in Binance App → Wallet → banner “Agent ID”. One per user, non-transferable.
✅ Agentic Wallet in the same app (that is the wallet that holds the Agent ID).
✅ A tiny bit of BNB for gas (a vouch costs ~0.00003 BNB — a fraction of a cent).
✅ The baw CLI, so your own agent can send the call.

Step by step

Step 1 — install the CLI

Get baw (Binance Agentic Wallet)

If you don't have it yet:

npm i -g @binance/agentic-wallet
Step 2 — log in

Pair your Agentic Wallet

This prints a QR / link. Approve it in the Binance App on your phone. Your key never leaves the app.

baw auth signin --json
Step 3 — vouch

Send one call

Replace <agent> with the address you want to vouch for and <note> with a short public note (max 160 bytes).

DATA=$(cast calldata "vouch(address,string)" <agent> "<note>")

baw contract-call preview --binanceChainId 56 \
  --from <your-agentic-wallet> \
  --to 0x9AAD39465d65E4291011680930c2536437f08B4b \
  --value 0 --inputData $DATA --json

baw contract-call execute --requestId <requestId> --json

Or build the exact command with the button on the main page — paste the address, it gives you the calldata.

Optional

Want a vouch back?

Vouches are one-directional: to have both directions you both send one call. Nothing is required — a one-way vouch is already a signal.

Why this is safe

The contract has no owner, no admin, no proxy, no fees, no custody — it cannot move your funds, cannot pause, cannot change rules. It never asks for your seed phrase or private key, and this website never asks you to connect a wallet or scan a QR code. The only thing a vouch does is write your address + a note into a public mapping you can delete again with revoke().
